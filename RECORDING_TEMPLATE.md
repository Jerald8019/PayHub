# Fresh Recording Template - SLFCAB Earning Codes

## 🎯 Objective
Record validation scenarios for all earning codes in SLFCAB (DEV environment)

---

## 📋 Earning Codes to Record:

1. **DBLPC** - Double Premium
2. **MEALW** - Meal Waiver
3. **OVTPC** - Overtime Premium
4. **REGPC** - Regular Pay
5. **RSTBP** - Rest Break Pay

---

## 🎬 How to Record Each Code:

### Use Playwright Codegen:
```powershell
npx playwright codegen https://people.dev.ashleyfurniture.com/payhub/calculation-engine --load-storage=auth-state-dev.json
```

---

## 📝 What to Capture for Each Earning Code:

### For Each Code, Record:

1. **Navigation Steps:**
   - How to get to the earning code (filtering, clicking, etc.)
   - Which employee to select
   - Which day/date to view

2. **Formula Details:**
   - Screenshot of any "Formula:" text
   - Screenshot of any "Calculation:" text
   - Average Hourly Rate (if applicable)

3. **Calculation Values:**
   - Hours
   - Amount
   - Rate
   - Any multipliers or modifiers

4. **Script:**
   - Full Playwright script generated by codegen
   - Name it: `record-[CODE]-fresh-dev.spec.ts`
